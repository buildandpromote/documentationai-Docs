## Prerequisites

<Callout kind="info">

Untapped Asset is currently in private beta. You need an invitation to access the dashboard. Ensure you have a valid email address and own digital assets like domains ready to list.

</Callout>

## Register Interest

Start by registering your interest to receive an invitation.

<Steps>
  <Step title="Visit the Registration Page" icon="external-link">
    Go to the [interest form](https://untappedasset.com/#interest) on the Untapped Asset homepage.
  </Step>
  <Step title="Fill Out the Form">
    Provide your name, email, and details about your assets (domains, websites, etc.).
    
    ```
    Name: Your Full Name
    Email: your.email@example.com
    Assets: example.com, myblog.net
    ```
  </Step>
  <Step title="Submit and Wait">
    Submit the form. You will receive a confirmation email. Invitations are sent on a rolling basis.
  </Step>
</Steps>

## Invitation and Account Creation

Once invited, create your account.

<Steps>
  <Step title="Check Your Email" icon="mail">
    Look for an invitation email from Untapped Asset containing a unique link.
  </Step>
  <Step title="Click the Invitation Link">
    Open the link to start account creation. It directs to `https://app.untappedasset.com/invite`.
  </Step>
  <Step title="Set Password">
    Enter a strong password and complete any verification steps, such as email confirmation.
  </Step>
</Steps>

## Login to the Dashboard

Access your dashboard securely.

<Tabs>
  <Tab title="Web Browser" icon="globe">
    Navigate to `https://app.untappedasset.com/login` and enter your credentials.
  </Tab>
  <Tab title="Magic Link" icon="link">
    Request a magic link via email for passwordless login.
    
    ```
    Click "Send Magic Link" on the login page.
    ```
  </Tab>
</Tabs>

<Callout kind="tip">
  Enable two-factor authentication (2FA) immediately after first login for added security.
</Callout>

## Next Steps

<Expandable title="Troubleshooting Common Issues" default-open="false">
  
| Issue | Solution |
|-------|----------|
| No invitation email | Check spam folder and resubmit interest form. |
| Login fails | Reset password via `https://app.untappedasset.com/forgot-password`. |
| Asset not visible | Verify ownership via DNS records as prompted. |

</Expandable>

Now list your first asset:

<CodeGroup tabs="CLI,Web">
  ```bash
  untapped-asset login --email your.email@example.com
  untapped-asset asset add example.com --type domain --price 1000
  ```
  ```javascript
  // Using the JS SDK (coming soon)
  import { UntappedAsset } from 'untapped-asset-sdk';
  
  const client = new UntappedAsset({ apiKey: 'YOUR_API_KEY' });
  await client.assets.create({
    name: 'example.com',
    type: 'domain',
    price: 1000
  });
  ```
</CodeGroup>
